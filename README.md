# BigData Fantasy

Aplicación web (PWA) que analiza tu liga privada de LaLiga Fantasy: valor y liquidez de cada mánager, mercado, cláusulas, puja máxima rentable con tres niveles de riesgo, comparador de jugadores y chat con IA generativa que responde sobre los datos reales de tu liga. Multiusuario y de solo lectura sobre el juego.

App en producción: https://bigdatafantasy.com

Copia pública de demostración: instantánea sin historial de una versión anterior (etapa Vercel, septiembre de 2026); en producción corre una versión más reciente y el repositorio de desarrollo es privado. El chat con IA está implementado y cableado en esta copia; para usarse requiere una clave propia de Gemini (variable GEMINI_API_KEY). Sin datos ni claves: toda la configuración es por variables de entorno (.env.example). Suite de tests: 59/59.
